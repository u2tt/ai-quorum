## 5. 数值是怎么算出来的（可复核）

### 5.1 对比度

标准 WCAG 2.1 相对亮度公式，sRGB 每通道先线性化：

```
c' = c/12.92                     (c ≤ 0.04045)
c' = ((c+0.055)/1.055)^2.4       (c > 0.04045)
L  = 0.2126R' + 0.7152G' + 0.0722B'
CR = (L_light + 0.05) / (L_dark + 0.05)
```

已用**独立第二实现**交叉校验（`#ffffff` vs `#000000` = 21.00；`#7c8798` vs `#1a2941` 两套代码都得 4.02），无实现偏差。

### 5.2 半透明怎么合成

先定不透明底，再**从底到顶**逐层 `out = top*a + bottom*(1-a)`：

| 组件 | 合成链 | 结果底色 |
|---|---|---|
| `body` | canvas `#ffffff` → `--bg #0B0E14` → radial-gradient 取最亮 stop `rgba(91,157,255,.10)` | `#131c2c` |
| `#configPane`（`.q-card`） | `--surface-1 #11151d` → 180° 白渐变 `rgba(255,255,255,.022)` | `#161a22` |
| 正方气泡 | body 底 → `.bubble` 135° 渐变取较亮端 `rgba(91,157,255,.10)` | `#1a2941` |
| 反方气泡 | body 底 → `rgba(255,107,157,.10)` | `#2b2437` |
| 弹窗卡片 | `.modal` 遮罩 `rgba(3,4,8,.6)` 在卡片外层；卡片自身 `--surface-2` 不透明 | `#1c2230` |
| `.vc-empty` | 卡片底 → 13.5px 前景 `rgba(255,255,255,.18)` 叠到底上 | `#40444b` |
| `#topInput` 占位符 | `#configPane` 底（输入框 `background:transparent`） | `#161a22` |
| 禁用按钮 | 父级底 → 按钮渐变 **α=.4** → 文字再 **α=.4** | `#2f4b77` / `#1f3554` |
| 渐变一律取「**较亮**的一端」入算 | 保证结论偏保守（亮底 = 深字更不利） | — |

### 5.3 动态组件怎么覆盖

气泡 / 裁决卡 / 历史行 / toast / 席位槽 / `.custom-row` 都是 JS 生成，静态 HTML 里是空容器。
脚本按 `createBubble`、`renderVerdict`、`vcCellHtml`、`histHtml`、`slotHtml`、`emptyHtml` 的真实类名结构，**在内存里**注入 8 组探针后再求级联（磁盘文件未改动）。
